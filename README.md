# 코드네임: 레드 (Codename: RED) — 모바일 웹 프로토타입

3분 안에 끝나는 잠입 미니게임 3종을 **설치·가입 없이 링크 하나로** 바로 체험하는 모바일 웹 버전입니다.
기획서 v0.1의 프로토타입 게이트("손맛 테스트")를 웹에서 바로 돌려 보기 위한 빌드입니다.

## 바로 실행

빌드 과정이 없는 정적 사이트입니다 (Vanilla JS · **Three.js 3D** · WebAudio). Three.js(r169)는 `vendor/`에 포함되어 있어 CDN 없이 동작합니다.

```bash
python3 -m http.server 8000
# 휴대폰과 같은 Wi-Fi에서 http://<PC IP>:8000 접속
```

ES 모듈을 쓰므로 `file://`로 열면 동작하지 않습니다. 정적 호스팅(GitHub Pages, Vercel, Netlify, S3 등) 어디에나 그대로 올리면 됩니다.
`.github/workflows/pages.yml`이 포함되어 있어, 저장소 설정 → Pages → Source를 **GitHub Actions**로 바꾸면 `main` 푸시마다 자동 배포됩니다.

- `?play=1` — 타이틀을 건너뛰고 바로 브리핑으로 (QR·광고 랜딩용)
- `?play=1&piece=clou` — 특정 피스 미션으로 바로 진입 (`panthere-brooch`, `love-bracelet`, `trinity-ring`, `panthere-ring`, `clou`)

## 비주얼 방향 (v0.2 · 3D)

- **메뉴 = 메종의 종이**: 상아색 바탕, 검정 글자, 자간 넓은 대문자 라벨(Jost), 대비 높은 세리프(Cormorant Garamond · Noto Serif KR), 모서리 없는 검정 버튼, 1px 구분선. 화면 절반은 비우고 그 자리에 3D 보석을 둡니다.
- **타이틀**: 아이보리 스튜디오에서 열린 레드 박스 안의 '오늘 밤의 의뢰' 피스가 천천히 회전.
- **게임 = 밤의 메종**: 검은 대리석 바닥, 아르데코 금빛 선, 붉은 레이저 커튼, 샹들리에 불빛, 금고는 로즈·옐로·화이트 골드 PBR 링, 전시실은 검은 벨벳 진열대와 스포트라이트 하나.
- 붉은색은 레이저·레드 박스·정체 드러남 같은 결정적 순간에만 씁니다.
- 모든 3D 모델(레드, 관리인, 피스 5종, 레드 박스, 샹들리에)은 코드로 만든 절차적 모델이며 외부 에셋 파일이 없습니다.
- 카메라는 화면 비율에 맞춰 거리를 자동 계산해 어떤 휴대폰에서도 잘리지 않습니다.

## 한 판의 흐름 (약 2~3분)

| 구간 | 조작 | 기획서 |
| --- | --- | --- |
| 1단계 붉은 복도 · 레이저 회랑 | 누르고 있기 = 전진, 떼기 = 팬더 자세(정지), 위로 쓸기 = 도약, 아래(또는 오른쪽)로 쓸기 = 슬라이딩 | 6-1 |
| 야간 관리인의 시선 | 바닥의 샹들리에 불빛 안에서 움직이면 시선이 쌓임 → 빛이 오면 손 떼기 | 6-4 |
| 2단계 지하 금고실 · Love / Trinity 금고 | 원을 따라 드래그해 회전, 정답(±3°)에서 0.5초 멈추면 딸깍. 정답 3개 | 6-2 |
| 야간 관리인의 시선 | 위와 동일 | 6-4 |
| 3단계 비밀 전시실 · 벨벳 레플리카 | 길게 눌러 무게 채우기 → 금빛 띠 안에서 떼기 (센서 3중 = 3회) | 6-3 |

- **시선 게이지**: 레이저 접촉 +40%(견습 +30%), 금고 크게 지나침 +15%, 바꿔치기 실패 +50%. 100%면 "정체가 드러났습니다" → 해당 단계부터 다시 방문 (재시작 3초 이내).
- **회수 등급**: 전설 S(시선 0%, 정체 드러남 없음, 완벽한 손놀림 2회 이상, 3분 이내) / 우아함 A(시선 30% 이하) / 회수 B.
- **팬더 인장**: 전설 난이도 S등급만. 인장 시 레드 박스 연출 + 비밀 거래 암호코드 화면 (체험판은 실물 초대장 미발급 안내).
- **나의 살롱**: 컬렉션 북 5피스(실루엣 → 진열 → 전용 조명 → 팬더 인장), 남긴 방문 카드 수, 괴도의 도구 3종(실크 장갑·시계공의 루페·적외선 모노클).
- **자랑**: 결과 화면의 "방문 카드 공유하기" — Web Share API(모바일 공유 시트), 미지원 시 클립보드 복사.
- 기록은 브라우저 `localStorage`에만 저장됩니다 (가입 없음).

## 난이도 (`js/data.js`)

| | 견습 | 프로 | 전설 |
| --- | --- | --- | --- |
| 레이저 패턴 주기 | 2.0초 | 1.4초 | 0.8초 |
| 꺼지기 전 예고 | 0.3초 | 0.22초 | 0.15초 |
| 금고 판정 | ±5° | ±4° | ±3° |
| 바꿔치기 띠 폭 | 16% | 11% | 7% (+게이지 흔들림, 관리인 2초 창) |

모든 수치는 기획서처럼 초기 가정값입니다. 기획서의 "레이저 개수 3→8"은 회랑이 8초 만에 끝나 버려, 한 구간이 약 30~40초가 되도록 전체 개수(7/10/13)로 늘려 잡았습니다.
자동 플레이 봇으로 세 난이도 모두 무접촉 클리어가 가능한 것을 확인했습니다.

## 웹 버전에서 달라진 점

기획서는 햅틱 품질 때문에 네이티브 앱을 권장합니다. 웹 버전은 다음처럼 대응했습니다.

- **진동**: Web Vibration API 사용 (Android 크롬 지원). **iOS 사파리는 진동 API가 없어** 화면 가장자리 빛·금빛 번짐·소리로 같은 정보를 전달합니다. (기획서 11장의 "햅틱 저품질 기기는 시각·소리 피드백으로 대체"와 같은 방식)
- **사운드**: 음원 파일 없이 WebAudio로 합성 (느린 재즈 베이스·브러시, 째깍/딸깍, 레드 박스 경첩 소리). 시선이 오를수록 템포가 빨라집니다. 첫 터치 시 오디오가 켜집니다.
- **접근성**: 설정의 "금빛 번짐"(소리 없이 금고 근접 표시, 기본 켜짐), "판정 범위 완화"(켜면 S등급·인장 기록 제외).

## 범위 밖 (서버가 필요한 기능)

친구 살롱 방문·답방, 서클(이번 주의 레드), 매장 예약·일회용 QR, 입력 로그 검증은 서버가 필요해 이번 프로토타입에서 제외했습니다.
결과 화면에 집계용 데이터(시간·시선·완벽한 손놀림·팬더의 걸음)는 이미 계산되므로, 서버 연동 시 그대로 전송하면 됩니다.

## 브랜드 관련

기획서 전제(브랜드사 공식 라이선스)를 따르되, 프로토타입에는 로고·실제 제품 3D 에셋을 쓰지 않고 컬렉션의 기호(표범, 나사, 세 가지 색 링, 못, 사각 시계)를 단순한 선 그림으로만 표현했습니다.
공개 배포 전 컬렉션 명칭 사용을 포함해 브랜드사 승인이 필요합니다.
