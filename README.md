# 🏎️ KART RACER

카트라이더 스타일의 탑다운 카트 레이싱 게임입니다. 별도 설치나 빌드 없이 `index.html` 하나로 실행됩니다.

## 실행 방법
`index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다. (PC 키보드 / 모바일 터치 모두 지원)

## 조작법
| 키 | 동작 |
|---|---|
| `↑` / `W` | 가속 |
| `↓` / `S` | 브레이크 / 후진 |
| `←` `→` / `A` `D` | 조향 |
| `Shift` | 드리프트 (방향키와 함께) |
| `Ctrl` / `Z` | 니트로 부스터 사용 |
| `R` | 재시작 |
| `Esc` | 메뉴 |
| `M` | 소리 켜기/끄기 |

## 게임 특징
- **드리프트 & 부스터 게이지**: 드리프트하면 게이지가 차고, 가득 차면 니트로를 1개 얻습니다 (최대 2개).
- **순간 부스터**: 드리프트를 0.4초 이상 유지한 뒤 떼면 짧은 가속.
- **출발 부스터**: 카운트다운 GO 직전에 가속키를 누르면 빠르게 출발.
- **부스터 패드**: 트랙 위 파란 화살표 패드를 밟으면 가속.
- 3개 트랙 (숲속 서킷 / 사막 캐니언 / 설원 스피드웨이), 3단계 난이도, 5명의 AI 라이벌
- 3랩 레이스, 실시간 순위, 미니맵, 랩 타임, 트랙별 최고 기록 저장
- 스키드 마크, 부스터 불꽃, 효과음 (Web Audio)
